JobsTracker

Herramienta personal de seguimiento de postulaciones de empleo.

JobsTracker es una aplicación de uso personal y de un solo usuario, desarrollada por Leonardo Mendoza Martínez para organizar su propia búsqueda de empleo. No es un producto comercial, no se ofrece a terceros y no tiene registro de usuarios.

Qué hace

Los correos que mueven un proceso de selección —un acuse de postulación, una citación a entrevista, una prueba técnica con fecha límite, un rechazo— llegan mezclados con el resto del buzón y es fácil que pasen desapercibidos. JobsTracker lee esos correos, reconoce a qué postulación corresponde cada uno y mantiene un tablero con el estado de cada proceso.

  • Lee el correo del propio usuario mediante la API de Gmail, en modo solo lectura.
  • Reconoce los mensajes transaccionales de portales de empleo y sistemas de selección.
  • Guarda el resultado en una base de datos local, en el computador del usuario.
  • Envía un aviso a un bot privado de Telegram cuando algo requiere atención.

La aplicación no puede enviar, responder, mover ni borrar correo. El único permiso que solicita es gmail.readonly.

Dónde viven los datos

En el computador personal del usuario. No hay servidor, no hay base de datos compartida y no se transmite información a terceros. El detalle completo está en la política de privacidad.
