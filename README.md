# L30N4RD018.github.io

Sitio estático mínimo que respalda la aplicación OAuth **JobsTracker** en Google Cloud.

Google exige que una app OAuth externa en producción declare página principal, política de
privacidad y condiciones del servicio en un dominio propio. Eso es todo lo que hay aquí.

| Archivo | URL | Para qué |
|---|---|---|
| `index.html` | `/` | Página principal de la aplicación |
| `privacidad.html` | `/privacidad.html` | Política de Privacidad |
| `condiciones.html` | `/condiciones.html` | Condiciones del Servicio |

Sin dependencias, sin JavaScript, sin recursos externos. `estilo.css` respeta el tema del sistema.
