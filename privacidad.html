Política de Privacidad

JobsTracker · Última actualización: 22 de agosto de 2026

JobsTracker es una aplicación personal, de un solo usuario, desarrollada y operada por Leonardo Mendoza Martínez. No se ofrece a terceros, no admite registro de otras personas y no tiene ánimo de lucro. El único usuario cuyos datos trata la aplicación es su propio desarrollador.

Qué datos se tratan

DatoDe dónde salePara qué
Contenido y metadatos de mensajes de correo API de Gmail, permiso gmail.readonly Identificar correos de procesos de selección y extraer de ellos empresa, cargo, fecha y estado
Dirección de correo de la cuenta API de Gmail Confirmar sobre qué cuenta se está trabajando
Identificador de chat de Telegram El propio usuario, al escribirle a su bot Enviar los avisos a ese chat y a ningún otro

La aplicación solo consulta correos de un conjunto reducido de remitentes conocidos —portales de empleo y sistemas de seguimiento de candidatos—. No indexa el buzón completo.

Permisos de Google que se solicitan

Uno solo:

  • https://www.googleapis.com/auth/gmail.readonly — lectura de mensajes y su configuración.

Este permiso es de solo lectura. La aplicación es técnicamente incapaz de enviar, responder, reenviar, etiquetar, archivar o eliminar correo, porque Google no le concede esas capacidades con este permiso.

Dónde se almacenan los datos

  • Los datos extraídos se guardan en una base de datos SQLite en el computador personal del usuario. No hay servidor remoto ni base de datos alojada.
  • Las credenciales de acceso (el token de OAuth de Google y el token del bot de Telegram) se guardan en el llavero del sistema operativo (Secret Service de freedesktop), no en archivos de texto.
  • No se guarda copia de los correos completos: solo los campos extraídos y una referencia al identificador del mensaje original.

Con quién se comparten

Con nadie. No se venden, alquilan ni ceden datos. No se transfieren a terceros. No se usan para publicidad ni para elaborar perfiles. No se emplean para entrenar modelos de inteligencia artificial, ni propios ni de terceros.

Los únicos servicios externos que intervienen son:

  • API de Gmail (Google), de donde se leen los correos.
  • API de Telegram, a la que se envía el texto del aviso, dirigido exclusivamente al chat privado del propio usuario.

Uso limitado de los datos de Google

El uso y la transferencia que JobsTracker hace de la información recibida de las APIs de Google se ajusta a la Política de Datos de Usuario de los Servicios de la API de Google, incluidos sus requisitos de Uso Limitado. En particular, los datos obtenidos de Gmail se emplean únicamente para la funcionalidad descrita en esta página, visible para el propio usuario, y no se transfieren a terceros salvo obligación legal.

Cuánto tiempo se conservan

Mientras el usuario mantenga la aplicación instalada. Al ser una base de datos local, borrar el archivo elimina los datos de forma definitiva.

Cómo revocar el acceso

En cualquier momento, desde myaccount.google.com/permissions, seleccionando JobsTracker y retirando el acceso. A partir de ese momento la aplicación deja de poder leer correo. Los datos ya extraídos se eliminan borrando la base de datos local.
